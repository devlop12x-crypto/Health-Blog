# 🌿 Noemi — Health Blog

Дипломный проект по вёрстке. Адаптивный блог о здоровье, образе жизни, путешествиях и еде. Выполнен на чистом HTML и CSS без фреймворков и библиотек.

![License](https://img.shields.io/badge/license-MIT-lightgrey) ![Stack](https://img.shields.io/badge/stack-HTML%20%7C%20CSS%20%7C%20SVG-orange)

---

## Что сделано

- **Хедер** — логотип в SVG, навигация, бургер-кнопка для мобильных устройств
- **Секция трендов** — сетка из 4 статей с изображениями и тегами
- **Лента постов** — карточки с превью, категориями, датой и описанием
- **Сайдбар** — дополнительный контент рядом с лентой
- **Адаптивная вёрстка** — корректно отображается на мобильных, планшетах и десктопе
- **Кастомные шрифты** — подключены локально через `@font-face`
- **SVG-иконки** — логотип и декоративные элементы

---

## Структура проекта

```
mq-diploma/
├── css/

│   └── noemi-logo.svg   # Логотип блога и SVG-иконки

```

## Категории контента

Блог охватывает темы: `lifestyle` · `health` · `food` · `travel` · `music` · `interior`

---

## Стек

- **HTML5** — семантическая разметка (`article`, `section`, `nav`, `time`, `address`)
- **CSS3** — Flexbox, Grid, кастомные шрифты, медиазапросы
- **SVG** — векторный логотип и иконки
- Без JavaScript, без фреймворков, без препроцессоров
